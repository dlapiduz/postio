# Contract: Composer Commands

**Consumers**: the keymap, the `Ctrl+K` palette, the `?` cheat sheet, the
context menu, row key hints, `docs/keybindings.md`, and `[keys]` in
`config.toml`.

Constitution II: all of those are generated from one table,
`postio-core::registry`. **A command that is not in the registry does not
exist** — not merely unbound, but absent from every way a user could find it.

**Command ids are a file format.** They are the key `[keys]` overrides are
written against, so renaming one breaks a user's configuration silently. They
are not renamed casually.

## What this feature relies on, and must not break

| Command id | Binding | Contract |
|---|---|---|
| `compose` | `c` | Opens a new draft (FR-007, FR-008) |
| `reply`, `reply_all`, `forward` | `e`, `E`, `f` | Open a draft answering the focused message (FR-040 to FR-043) |
| `send` | `mod+Return` | Local-first, undoable for a grace period (FR-065, FR-059) |
| `schedule_send` | `mod+shift+Return` | States when it will go; cancellable (FR-053) |
| `save_draft` | `mod+s` | Explicit save; automatic saving is FR-047 and is not a command |
| `discard_draft` | `mod+d` | Asks first — the one composer action that cannot be undone (FR-061) |
| `mark_sent` | `mod+shift+m` | (FR-051 territory) |
| `attach_file` | `mod+shift+a` | Attach by keyboard (FR-053) |
| `detach_composer` | `mod+shift+o` | Deliberate, never the default (FR-009) |
| `bold`, `italic`, `bullet_list`, `numbered_list`, `insert_link`, `quote_block` | see `docs/keybindings.md` | The formatting vocabulary — and the bound set markdown input may produce (FR-068) |

## Rules this feature adds

1. **Markdown input introduces no command.** It is an input method that reaches
   the existing ones (FR-067, FR-068). If a markdown sequence would need a verb
   the registry does not have, the sequence is out of scope, not the registry.
2. **The editor's appearance introduces no command.** It follows the
   application's colour scheme and text size; it is not a per-draft setting.
3. **Any verb this feature does add** — should a task find one necessary —
   enters the registry with a binding, a palette entry and an accessible
   control, and `docs/keybindings.md` is regenerated by its own test.

## How it is verified

`docs/keybindings.md` is generated from the registry by a test that fails when
it drifts. The palette and cheat sheet read the same table. So the contract is
enforced by construction; what a task must not do is reach around it — a button
wired straight to a handler is a command that exists for the mouse and not for
anyone else.
