# Gotchas

Live traps no check or hook stops. Read the file for the area you touch; history is in `docs/archive/`.

- `gotchas/tests.md`: before writing or debugging a test, storyboard or headless GTK suite.
- `gotchas/store.md`: before touching SQL, the schema, the search index or body fetching.
- `gotchas/sync.md`: before touching sync, IMAP, OAuth, accounts or the MCP socket.
- `gotchas/gtk.md`: before touching widgets, CSS or key handling.
- `gotchas/macos.md`: before touching `postio-ffi` or `macos/`.
- `gotchas/build.md`: before touching builds, caches, scripts, worktrees, git or CI.
- `gotchas/safety.md`: before touching logging, secrets, fuzzing or parsing hostile input.
- `gotchas/signatures.md`: before touching signatures.
