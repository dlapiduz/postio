A mail client for people with too much email · 0.4 alpha

Read less. Find anything. Act faster.

Postio is a local-first, keyboard-first email client for Linux. Your mail is kept in an encrypted local store with a full-text index, so search and navigation never wait on the network — and every action you take applies instantly, offline or not.

Get Postio Read the guide

Instant

Opening the app is immediate, because there's nothing to wait for — mail already synced locally is already on screen. Every archive, flag, move, snooze or delete applies to your local copy right away; the server catches up in the background.

Search-first

One query box searches mail, jumps to a folder, or finds a person — from:ada has:attach after:2026-01-01 — and it's local, so results appear as you type instead of after a round trip. Save a search and it is one key away.

Keyboard-first

Every command has a shortcut, a place in the command bar, and an accessible action, generated from one table so the three can't drift apart. e replies, a archives, Ctrl+Z undoes anything — the mouse stays excellent and is never required. Every binding →

The inbox

Mail as it arrived, and what it asks of you

One dense list, newest first: sender, subject and first line, verbatim. An invitation, a direct question or a to-do is called out on its row, quoting the sentence that raised it, with the key that answers it — y to accept, e to reply, s to snooze. ! shows only what needs you. Newsletters can wait for a digest on the day you choose, and spam and automated updates are filed into Filtered, each with its reason and one key from restored.

Search

Search is how you move, not a box in the corner

One bar, / for mail and Ctrl+K for commands. Type and the results narrow as you go. Operators compose — from:, in:, has:attach, is:unread, after:, larger:, account: — and a leading - negates. Plain words such as "Marisol sent last month" become operators you can see. Ctrl+S saves a search, and Alt+1…Alt+4 run the pinned ones.

Compose

Writing never makes you lose your place

The composer opens where the message was, over the list, rather than in a separate window — the list keeps its scroll position and its cursor right where you left them. Reply with the original folded under your text, write rich text with the usual keys, attach a file, send now or later, and Esc puts you back exactly where you were without discarding a word.

Accounts

All your accounts, one inbox

Add as many IMAP, Gmail or JMAP accounts as you have. Each is synced by its own engine, and the inbox shows every account's mail together — a slow or unreachable server never holds the others back, and search says so rather than leaving a gap. g o reaches every mailbox, folder and label. Sign in with a password, an app-specific password, or OAuth 2 through your browser.

Native

A real desktop application, in light and dark

GTK4 and libadwaita, in your desktop's font, accent and theme, following its text scaling and reduced-motion settings. Notifications for the folders you choose, and transitions of a hundred milliseconds or none at all.

Privacy

Nothing leaves this machine that you didn't ask for

Email is the most sensitive thing on most people's machines, and mail is content designed to phone home. Postio treats that as a design constraint, not a checkbox.

Remote images stay blocked

Tracking pixels and remote images load only after you allow them, per sender — never on by default.

Read receipts are never automatic

Disposition-Notification-To is tracking with a friendly name, and Postio doesn't send one without you asking. One-click unsubscribe fires only when you click it.

No speculative connections

No link prefetch, no favicon fetch. The message reader runs no script that arrived in a message and has network access off; images referenced by cid: resolve from what already synced.

Encrypted at rest, no telemetry

The local store is encrypted and the key lives in your OS keyring, beside your credentials — never in a config file, never in a log. No crash reporting, no update ping, no analytics — on this page either.

Under the hood

Local-first isn't a tagline here — it's how the app is built

Every action follows the same rule: write to the local store, queue the network operation, repaint. The network is never in the critical path of anything you do — which is also what makes offline just the normal case rather than a special mode.

An encrypted store with its own index

Mail metadata, threads, bodies and sync state live in Turso, a Rust rewrite of SQLite, encrypted page by page and indexed by its built-in full-text search; raw messages and attachments sit in a content-addressed blob store. Nothing is ever loaded into memory all at once — the message list is windowed over paged queries, even at hundreds of thousands of messages.

One vocabulary, every surface

Every command in Postio — keyboard shortcut, command-bar entry, accessible action — comes from a single registry table. A command that isn't in it doesn't exist anywhere in the UI, which is what keeps the keyboard, the mouse and a screen reader in agreement.

Threading Postio can trust

Conversations are reconstructed locally with JWZ threading over message headers, using whatever a server offers as a hint and never as the answer — so a server that threads badly doesn't make Postio thread badly.

This codebase is almost entirely AI-generated. Postio is written by AI coding agents under a human maintainer who sets scope, reviews the results, and makes the product calls. Every piece of work is a GitHub issue worked in its own branch; test-driven development is mandatory; the invariants above — no SQL in the view layer, no message content in a log, a destructive command must be undoable — are checked by the build, not just remembered. The reasoning for every non-obvious decision is written down as an architecture decision record, in public.

Status

What 0.4 does, and what it doesn't yet

Postio 0.4 is an alpha: more complete than the number suggests, and still early software. Keep your current client around until you trust it. The issue tracker is the live picture; this is the shape.

  • Built

    Mail, the whole of it

    Several accounts with a unified inbox. IMAP and SMTP, Gmail and JMAP. Password, app-specific password or OAuth 2. Folders, threads and labels; read, archive, delete, flag, move, snooze. HTML and plain-text reading with attachments and quoted-text folding. Rich-text compose, reply, forward, drafts, scheduled send, and an outbox that never sends twice. Background sync with IDLE, full offline use, undo.

  • Built

    Search, saved searches, contacts

    Local full-text search with operators, pinned saved searches, a spelling suggestion when a query finds nothing, and an address book with groups grown from the people already in your mail.

  • Not yet

    Filters and rules

    The same search language you'd type in the search bar, reused as the condition for a rule that files mail as it arrives — one language to learn, not two. Designed; not built.

  • Not yet

    macOS

    A native Swift frontend over the same engine reads mail, searches and pages today, and is built and tested — but not yet released. Windows is unscheduled.

  • Deferred by design

    AI — summarize, draft, search by meaning

    AI is a founding idea for Postio and is deliberately absent until the fundamentals are excellent on their own, beyond an optional local model you run yourself for digest summaries and spotting questions and to-dos. When it arrives, two rules are already fixed: it can never send or modify mail without you confirming in the Postio UI, and every request to a remote model is opt-in, per account, and logged where you can read it.

Install

Get Postio

Postio runs on Linux under Wayland, on GTK 4.20 and libadwaita 1.7 or newer. Every tagged release publishes a prebuilt Flatpak bundle with a signed build-provenance attestation, so a download can be checked rather than merely trusted.

The Flatpak bundle

Download postio-<version>-linux-x86_64.flatpak from the latest release and install it for your user. The bundle fetches the GNOME runtime from Flathub if you don't have it. 

flatpak install --user ./postio-<version>-linux-x86_64.flatpak
flatpak run dev.postio.Postio

Releases →

From source

One script builds a release binary and installs it under ~/.local, on your $PATH and in your app grid. The guide has the system packages for Fedora and Ubuntu. 

git clone https://github.com/dlapiduz/postio
cd postio && scripts/install-local.sh
