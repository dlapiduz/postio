# ADR 0047 — One feature set for the workspace

- **Status:** Accepted (2026-10-09). Built.
- **Decision:** Every member depends on `postio-workspace-hack`, a codeless crate that names each third-party crate so the workspace builds one feature union, generated by `cargo hakari`. A crate boundary is about what a crate's code can call, and the hack gives it nothing to call.

## Rules
- The crate is `crates/postio-workspace-hack`, generated from `.config/hakari.toml` for Linux on both arches and the Mac, and depended on through `postio-workspace-hack.workspace = true`. After any dependency change: `cargo hakari generate && cargo hakari manage-deps --yes`.
- Boundary rules (`ARCHITECTURE.md`, ADR 0042) mean crates reachable through real dependencies, with features as built. A banned crate the hack names is a violation once a real dependency reaches it. A feature the hack switches on in a crate a guarded crate calls is still that crate's feature.
- Excluded from unification:
  - `postio-ffi`: its `uniffi` takes `cli` (hence `default-members` omits it, #1306), and unified every crate would build `uniffi_bindgen` and `clap`.
  - `glib-sys`, `gobject-sys`, `gio-sys`: unified, every Linux build links GLib, including the terminal's Flatpak.
  - `image`: the renderer decodes hostile images with exactly four decoders (ADR 0042).
- A crate whose unified features change what it does in a way no check sees is excluded.
- Test-only features reach shipped builds (`tokio` `test-util`, which costs an atomic load). A test-only feature with a real cost is a reason to exclude that crate.
- Enforcement: `check-workspace-hack.py` (hakari diff and `manage-deps --dry-run`; CI installs the pinned tool via `scripts/install-hakari.sh`); `check-crate-boundaries.py` and `check-renderer-is-memory-safe.py` do not walk into the hack but keep its features; `check-unused-deps.py` leaves its dependencies to it.

## Why
- Per-command feature resolution rebuilt 311-362 third-party crates per `cargo check -p` or `test -p --lib` in a fresh worktree (253 s to 42 s, 601 s to 106 s with the hack, zero rebuilt).
- Cost accepted: pure crates wait on the hack's dependencies on a cold tree (166 s to 197 s); seeding keeps cold trees rare.
- Rejected: leaving pure crates out (317 rebuilt instead of 362, and storage rebuilt more); one shared target directory (serialises sessions on cargo's lock).

## Revisit when
- Cargo resolves features per workspace rather than per command.
