Postio 0.4.1 is an alpha, and the first release since the local store was rebuilt. The mail client is the same one the maintainer reads mail in every day; what changed underneath is the engine, and what changed on top is a long list of things that used to wait.

- The store is Turso, a Rust rewrite of SQLite, with its own full-text index and page-level encryption. Your mail is stored the same way; what is gone is the vendored SQLCipher and OpenSSL build underneath it.
- Search and navigation stay responsive while a large mailbox backfills: a keystroke takes priority over a sync pass for the store, and the full-text index of message bodies is built by its own task off the sync lane.
- Message bodies are compressed per row and stamped with the parser that read them, so a body an older parser got wrong is fetched again on the next sync instead of staying wrong.
- Messages whose quoted-printable encoding is not quite right are decoded leniently instead of showing "parts of this message could not be decoded".
- Settled operations are pruned from the queue after thirty days and the store reclaims space when it is worth doing.
- The macOS frontend over the same engine reads mail, searches and pages, and is built and tested but not yet released.
- A WebKit process that dies is reported at once, in the app and in the test suite, instead of surfacing as a four-minute timeout.
- A mailto: link from a browser or another application opens the composer with the address, subject and body filled in, including on a cold launch. The desktop entry had claimed the scheme since 0.1.0; the application had never handled it.
- The 0.3.0 milestone is included in this release: several accounts with a unified inbox, OAuth 2 sign-in through the browser, and the Gmail and JMAP backends. Its tag was cut on 2026-09-11 but its release never published, so this is the first bundle that carries it.
- There is no 0.4.0 bundle. That tag was cut on 2026-09-19 and its build stopped on the last step before the bundle, so nothing was ever published under it; 0.4.1 is the same contents, released.
