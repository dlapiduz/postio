Postio 0.6.0 is an alpha. It brings spec 010's search to Linux, so search works the same way on both platforms, and it moves Postio onto Rust 1.100 and the newest Pimalaya mail libraries, with the protocol and security fixes they carry.

- Search on Linux: the dropdown as you type, its suggestions and filter chips, and the results view with Quick Look are now on Linux, with the Mac's keys (Command read as Control).
- The results' From, To, Date, Anywhere and Label filters open from the keyboard: alt+f, alt+t, alt+d, alt+w and alt+l, each shown as a keycap on its button and in the View menu.
- Search reads more truthfully: a value nobody matches says so instead of showing an empty heading, People leaves you out of its count, a top hit's matches count toward Quick Look, and passages that arrive with the first page are no longer dropped.
- A flag change made just before archiving a message now reaches the server, and Filtered's decisions carry to your other machines.
- In the reader, Ctrl+C copies what you selected. A move's toast counts the messages you chose.
- On the Mac, Shift+Tab steps back through the composer, the message's buttons show hover and press, and the sync label stays inside its capsule.
- IMAP, SMTP, OAuth and JMAP move to the latest Pimalaya libraries:
  - After a MOVE or COPY, each message's new UID is paired with the right original.
  - A server's QRESYNC answer can no longer make Postio allocate gigabytes.
  - Passwords are SASLprep-prepared, and a SCRAM server's iteration count is bounded.
  - OAuth checks the issuer and the redirect's state.
  - A FETCH line that decodes only in part is never stored as a message missing its date or envelope. An incremental resync that lost one rebuilds the folder instead.
- Security: the HTML sanitizer is on ammonia 4.2.5 (RUSTSEC-2026-0533, mutation XSS through embedded SVG and MathML), and rustix on 1.1.6 (RUSTSEC-2026-0486).
- Under the hood: Rust 1.100, html5ever 0.40, zbus 6 with oo7 0.7 for the keyring, and the Flatpak bundles on GNOME 51 and freedesktop 26.08.
